Entry for make.fun's "One Word, First Thought" bounty ($5 in USDC): a pure-Python program that writes exactly one word to `entry.txt` — **petrichor**, the scent of earth after rain.

Why this word, against the judge's brief: it is surprising (an uncommon word few readers would guess), vivid and specific (one smell calls up a whole rainy afternoon), and carries a spark of sound and double meaning — *petr-* (stone) + *-ichor* (the blood of the gods). It is also short: 9 characters, which helps the smaller-text tie-break in the ranking. The program writes exactly the one word, no trailing newline, nothing else.

## Run it

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written (defaults to `/output`).
